# dagster_etl_project

Simple Dagster ETL pipeline. 
- Uses dlt to load Iris dataset from github. 
- Uses dbt to do some basic data transformation
- uses polars to create features
- model is trained using Sklean
- all the intermediate assets are stored in Duckdb
